he Z-Score method is a statistical technique used to detect and remove outliers from numerical data.

A Z-score tells us how many standard deviations a data point is away from the mean.

Formula
Z  = X-μ/σ​

The Z-score method detects outliers by measuring how many standard deviations an observation is away from the mean. 
A common rule considers observations with an absolute Z-score greater than 3 as potential outliers.
